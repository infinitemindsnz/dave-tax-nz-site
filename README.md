# Dave Ananth — Tax Barrister website concept

A modern, responsive redesign of Dave Ananth’s public tax barrister website, created as a standalone presentation project.

## Features

- High-contrast editorial design based on the selected “Strategic Advocate” direction
- Responsive desktop and mobile navigation
- Verified student-loan, IRD dispute and tax-debt content
- Working booking, phone, email, map, media and professional-profile links
- Filterable articles and media feed
- Automation-ready article data source in `src/articles.js`
- Accessible focus states, skip link, semantic structure and reduced-motion handling

## Local development

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run build
npm run test:sites
```
